Questions fréquentes

La position d'un membre ne se met pas à jour

  • Dans Réglages → Nestia → Position, choisissez « Toujours » et activez « Position exacte ».
  • Évitez de fermer Nestia en la balayant vers le haut : laissez-la en arrière-plan.
  • Vérifiez que le mode Économie d'énergie est désactivé et que l'iPhone a du réseau.
  • À l'arrêt, la position est mise à jour moins souvent pour économiser la batterie : c'est normal.

Je ne reçois pas les notifications

  • Dans Réglages → Nestia → Notifications, activez « Autoriser les notifications ».
  • Vérifiez que le mode Concentration ou Ne pas déranger est désactivé.

Comment inviter un membre ?

Dans l'onglet Cercles, partagez le lien ou le code d'invitation, ou faites scanner le QR code.

Comment résilier mon abonnement ?

Réglages de l'iPhone → votre nom → Abonnements → Nestia → Annuler l'abonnement. Vous gardez l'accès jusqu'à la fin de la période payée.

J'ai changé d'iPhone, je n'ai plus mon abonnement

Connectez-vous à votre compte Nestia, ouvrez l'écran d'abonnement et appuyez sur « Restaurer mes achats », avec le même identifiant Apple.

Comment demander un remboursement ?

Les paiements sont gérés par Apple : faites votre demande sur reportaproblem.apple.com.

Comment supprimer mon compte ?

Dans l'application : Profil → Supprimer mon compte. Toutes vos données sont effacées. Pensez à résilier votre abonnement dans les réglages Apple.

Urgence : Nestia n'est pas un service d'urgence. En cas de danger, appelez le 112.
